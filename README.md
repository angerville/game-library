# 디지털 시민성 게임 도서관 (버전 2)

대련한국국제학교 6학년 팀 프로젝트 게임을 Canva 없이 돌아가는 HTML로 다시 만든 폴더예요.
이 `game-web` 폴더 하나만 올리면 바로 배포돼요. (빌드 과정 없음)

```
game-web/
├─ index.html        ← 게임 도서관 첫 화면 (두 게임으로 가는 카드)
├─ mom/index.html    ← 1모둠 「무서운 엄마」 (AI 윤리 퀴즈)
├─ forest/index.html ← 2모둠 「숲속 퀘스트 어드벤처」 (저작권·출처 3D 탐험)
└─ assets/           ← three.js, 글꼴(주아·고운돋움) — 인터넷 CDN 없이 동작
```

외부 CDN을 쓰지 않아서 중국 학교 인터넷 환경에서도 글꼴과 3D가 막히지 않아요.

## 배포 방법 1 — Netlify (가장 쉬움)

1. https://app.netlify.com/drop 에 접속해 로그인해요.
2. `game-web` 폴더를 통째로 끌어다 놓아요.
3. 잠시 뒤 `https://○○○.netlify.app` 주소가 생겨요.
   - 게임 도서관: `https://○○○.netlify.app/`
   - 무서운 엄마: `https://○○○.netlify.app/mom/`
   - 숲속 퀘스트: `https://○○○.netlify.app/forest/`
4. 「Site configuration → Change site name」에서 주소 앞부분을 바꿀 수 있어요.

게임을 고친 뒤에는 「Deploys」 탭에 폴더를 다시 끌어다 놓으면 같은 주소로 갱신돼요.

## 배포 방법 2 — GitHub Pages

1. GitHub에서 새 저장소를 만들어요. (예: `game-library`, Public)
2. 「Add file → Upload files」로 `game-web` 폴더 **안의 내용물**(index.html, mom, forest, assets, README.md)을 올려요.
3. 「Settings → Pages」에서 Source를 `Deploy from a branch`, Branch를 `main` / `(root)`로 정하고 저장해요.
4. 1~2분 뒤 `https://아이디.github.io/game-library/` 주소가 생겨요.

## 내 컴퓨터에서 미리 보기

`index.html`을 더블클릭해도 대부분 열리지만, 3D 게임은 아래처럼 작은 서버로 여는 것이 가장 정확해요.

```bash
python -m http.server 8765 --directory game-web
```

그다음 브라우저에서 http://localhost:8765 을 열어요.

## 버전 2에서 바뀐 점

### 1모둠 「무서운 엄마」 — 기획서에 있었는데 빠졌던 것
- 상점 아이템 **엄마 기억 삭제 20元** (틀려도 용돈 받기)
- **틀리면 책으로 돌아가 복습**: 틀린 문제와 관련된 약속에 형광펜이 칠해지고, 다 읽어야 다음 문제로 가요. 틀린 문제는 나중에 다시 나와요.
- **승리 장면**: 팀이 직접 찍은 영상(`mom/media/win.mp4`)이 먼저 나오고, 끝나면 놀이터로 달려 나가는 그림 장면으로 이어져요. 영상은 PICO-8 색감의 도트 게임 화면(하트·코인·도트 자막 포함)으로 바꾸고, 얼굴은 도트 캐릭터로 가렸으며, 원래 소리는 뺐어요. (버그 공략집의 “너무 가짜 같다” 해결)
- 엄마 표정 4가지(보통·화남·폭발·기쁨), 3연속 정답 보너스, 문제·보기 순서 섞기, 효과음, 만든 사람·출처 화면

### 2모둠 「숲속 퀘스트」 — 모둠 추가 프롬프트 + 기획서에 있었는데 빠졌던 것
- 숲 **지도**(작은 지도 + `M` 키 큰 지도, 빠른 이동)
- 시작 화면에 **게임 플레이 방법**과 **출처: AI캔바**
- **오두막 30곳 · 문제 30개**, 오두막마다 서로 다른 문제(매 판 섞임), **20문제를 풀면 끝**
- 마지막 화면에 모둠이 정한 만든 사람·출처 그대로 표시
- **하트 5개**(틀리면 1개 줄고, 모두 잃으면 실패), **상점에서 사려면 출처 확인 문제** 맞히기
- 주인공 **스티븐 / 마리아** 고르기 (고르지 않은 친구는 광장에서 안내해 줘요)
- 꽃밭 힌트 종이(돋보기), 텃밭 딸기·수박·멜론, 버전 1 배경음악 선율 그대로 사용
- **레벨 업**: 5문제마다 등급이 올라요 (견습 탐험가 → 숲 탐험가 → 출처 탐정 → 저작권 수호자 → 숲의 크리에이터)
  - 캐릭터가 배낭 → 탐정 모자·망토 → 수호자 조끼 → 왕관으로 멋있어지고 조금씩 커져요.
  - 탈것 진화: 전기자전거 → 빛나는 갈기 말 → 나무 오픈카 → 날개 달린 말
  - 아기 여우 친구가 생겨 자라고, 15문제부터는 가까운 노란 오두막 쪽으로 길을 알려 줘요.
  - 푼 오두막 주변에 꽃이 피어나요. 레벨 업 카드에는 그 등급에서 푼 문제가 나와요.

## 문제·글을 고치고 싶을 때

- 무서운 엄마 문제: `mom/index.html`에서 `const QUESTIONS` 부분 (`c`는 정답 번호, 0부터 셈)
- 숲속 퀘스트 문제: `forest/index.html`에서 `const QUESTIONS` 부분
- 만든 사람·출처: 각 파일에서 `만든 사람`을 검색
